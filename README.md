# LLM Arena · 大模型竞技场

让模型在棋盘上比拼，而不是比较谁写的提示词更好。选择两位选手和井字棋或四子棋，开赛后实时观看落子。规则引擎裁定胜负，并将最近 20 场已完成的对局保存在当前浏览器。

## 试玩

需要 Node.js 22 或更新版本。不用安装依赖，也不用 API 密钥。

```sh
npm start
```

打开 <http://127.0.0.1:3000>，选择内置选手并点击「开始对局」。演示选手是不同策略的程序，不是真实 LLM。

## 接入真实模型

复制 `.env.example` 为 `.env`，填入想启用的服务商的 API 密钥和模型 ID，再启动：

```sh
node --env-file=.env server.js
```

- OpenAI 使用 Responses API；选择能以文本返回 JSON 的模型。
- Anthropic 使用 Messages API；选择能以文本返回 JSON 的模型。
- 每位选手可独立选择。可让两个服务商互相对弈，也可让模型对阵内置选手。

密钥只存于服务端；不要提交 `.env`。真实模型按回合调用，会产生 API 费用。非法落子判负；连线失败或超时会中止棋局，不记战绩。服务一次只接受一场真实模型对局。默认只监听本机；不要把加载了密钥的实例公开给不受信任的用户。共享部署前需要鉴权和用量限制。

## 验证

```sh
npm test
```

内置测试不调用付费接口。规则、选手适配器与对局服务相互独立；浏览器通过 NDJSON 流接收每步落子和结果。
