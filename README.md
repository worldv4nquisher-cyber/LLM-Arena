# LLM Arena · 大模型竞技场

让智能真正上场。首页是「星穹格斗场」：五位 AI 拟人选手在原创程序化 3D 庭院中对战，具有角色动作、能量弹、格挡、特效、解说、生命/能量条和三局两胜赛制。

**格斗目前是内置策略演示，不调用真实 LLM，也不消耗 API 额度。** 选手名称代表拟人形象，而非服务商模型的能力评测。可选择均衡、强攻或反击策略。服务端先计算完整赛况，浏览器再连续演出；支持暂停、0.5×/1×/2×、三种机位、可选音效、重播和最近 8 场本机记录。角色是 Three.js 原创程序化卡通模型，不是概念图的高精度建模；识别特征参考 [AI Girls Atlas](https://github.com/HABAI182/ai-girls-atlas)（ZipZipPipe；DeepSeek 原角色署名上善无形），未复制上游图像或模型素材。

原有井字棋 / 四子棋与真实模型接入完整保留在 `/classic`。其他赛事尚未实现。

## 试玩

需要 Node.js 22 或更新版本，以及支持 WebGL 2 的现代浏览器。不用 API 密钥；Three.js 从本机依赖提供，不使用 CDN。

```sh
npm ci
npm start
```

打开 <http://127.0.0.1:3000>，选择选手和战术，点击「开始比赛」。切换到其他浏览器标签页会自动暂停。无法启用 WebGL 时会提示，不会展示假比赛。要玩旧版棋局，打开 <http://127.0.0.1:3000/classic>。

格斗接口：`GET /api/fighters` 返回公开选手资料；`POST /api/fights` 接受 `{ "players": ["gpt", "claude"], "tactics": ["balanced", "counter"], "seed": 1 }` 并返回完整、可复现的赛况。`seed` 与 `tactics` 可省略；随机种子来自服务端。规则同时结算双方行动，不给先手额外优势；双 KO 为平局。

## 接入真实模型

真实模型接入目前只适用于 `/classic` 棋局，不适用于格斗。复制 `.env.example` 为 `.env`，填入想启用的服务商的 API 密钥和模型 ID，再启动：

```sh
node --env-file=.env server.js
```

- OpenAI 使用 Responses API；选择能以文本返回 JSON 的模型。
- Anthropic 使用 Messages API；选择能以文本返回 JSON 的模型。
- 每位选手可独立选择。可让两个服务商互相对弈，也可让模型对阵内置选手。
- 同一服务商可填写多个模型 ID，用英文逗号分隔（如 `OPENAI_MODEL=gpt-4.1,gpt-4.1-mini`），让它们同台对弈。
- 每步默认最多等待 30 秒，可用 `MODEL_TIMEOUT_SECONDS` 调整。

密钥只存于服务端；不要提交 `.env`。真实模型按回合调用，会产生 API 费用。非法落子判负；连线失败或超时会中止棋局，不记战绩，并提示是哪一方、哪个模型出错及原因（如密钥无效、模型不存在、额度不足、超时）。服务端日志会记录服务商返回的状态码。服务一次只接受一场真实模型对局。默认只监听本机；不要把加载了密钥的实例公开给不受信任的用户。共享部署前需要鉴权和用量限制。

## 验证

```sh
npm test
```

内置测试不调用付费接口。规则、选手适配器与对局服务相互独立；浏览器通过 NDJSON 流接收每步落子和结果。
